## 지금까지 한 것 (요약)

### 1. 시뮬레이션 환경 구축 & 기본 버그 해결
PX4 SITL + Gazebo(Harmonic) + MAVSDK-Python 환경 구축. **yaw rate 명령 비결정적
버그**: 이륙 후 목표 고도 도달 확인 없이 바로 Offboard로 넘어가 yaw 명령이 무시되던
문제 — `telemetry.position()`으로 실제 고도 도달 확인 후 전환하도록 수정.

### 2. 바람 외란 PID-only 베이스라인
`gz_x500_windy`에서 순수 PID가 바람에 얼마나 버티는지 측정. 강풍(8.5m/s)에서도
위치오차는 5cm 이내로 잡지만, roll/pitch가 바람 세기에 비례해 계속 기울어진 채
유지됨 — 이게 PINN이 추정할 대상.

### 3. PINN 바람 추정 모델
드론의 최근 상태(수평속도, roll, pitch)로 현재 바람벡터를 추정하는 작은 신경망.
지도학습 loss + 물리 법칙(항력 방정식) loss 병용.
- **고정바람 40개 조건**: 풍속 MAE **0.37~0.5 m/s**(평균풍속 4.6m/s 대비 약 10%)
- **gust(시간에 따라 변하는 바람) 포함**: 처음엔 MAE 1.8m/s로 악화, 모델 크기/정규화/
  데이터 추가 다 무효라 "모델 구조 자체의 한계"로 잠정 결론. **이 결론은 나중에
  뒤집힘** — yaw 그리드로 gust 데이터를 재수집하니 **0.36 m/s로 5배 개선**됨(6절
  참고). 진짜 원인은 모델 구조가 아니라 좁은 yaw 범위 데이터였음.

### 4. 추정치를 실제 제어에 연결
- **1차 시도(실패)**: 추정 바람만큼 position setpoint를 반대로 밀어줌 → 보정이
  setpoint를 흔들며 폐루프 발산(roll 수십도까지). PID가 이미 트림만으로 위치오차를
  거의 다 잡고 있어 위치 보정 자체가 안 맞는 지렛대였음.
- **2차 시도(성공)**: 목표 위치는 고정, 추정 바람 반대방향 **가속도만 추가**
  (`set_position_velocity_acceleration_ned`). 강풍 온셋 피크 위치오차 0.47m→0.21m
  (**-55%**).
- 5개 조건(무풍/약/보통/강/옆바람) A/B, deadband(무풍 시 보정 끄기) 추가 후
  **5/5 조건 개선**(+8.2%~+71.3%).
- **gust 확장 검증**(4조건, 진폭±60% 주기6초): 추정 자체가 부정확(3절)한데도
  **4개 중 3개 개선**(+23.5%~+33.6%), 약한 gust만 소폭 악화(-5.3%).
- **`ACCEL_GAIN`/`WIND_DEADBAND_MPS` 튜닝**: gain↑·deadband↓는 강풍엔 좋지만
  무풍/약풍엔 나빠지는 트레이드오프만 확인 — **원래 값(0.15/1.0)이 이미 최적**.
- **yaw 그리드 재학습 모델로 재검증**: fixed-wind A/B 4/5, gust A/B 4/4 유지.

### 5. 회전 방해토크(τ_disturbance) 확장 — 발산 해결 후 첫 순이익 달성
세미나 원 과제(`Jω̇=τ_motor+τ_disturbance`를 PX4 PID에 피드포워드)를 병진과 결합.
회전은 별도 라벨 없이 텔레메트리 물리잔차가 학습 신호.
- 자이로/액추에이터 로깅 추가, 15세션(2700조건) yaw 그리드 재수집 + 결합학습 +
  5-fold까지 **오프라인 성공**(회전 물리잔차 0.763±0.238). PX4 펌웨어
  (`mc_rate_control.cpp`)에 MAVLink DEBUG_VECT 기반 토크 피드포워드 채널 신규
  구현·캘리브레이션 검증.
- 실시간 A/B 1차: **폐루프 발산**(무풍에서도 21°+) — 각속도(wx/wy/wz)를 모델
  입력에 넣으면 보정이 자기 입력을 오염시키는 양성 피드백 형성. 게인 스윕·저역통과
  필터 재도입도 둘 다 실패(필터는 오히려 더 심하게 발산, 38.7°).
- **근본 원인**: 회전 물리손실이 모델 출력만 검사할 뿐 인과 추론을 강제 안 함 —
  모든 데이터가 무보정 상태라 네트워크가 "자기 입력을 미분해 돌려주는" 지름길을
  학습해버린 게 발산의 진짜 원인.
- **해결책**: 데이터 수집 중 실제로 무작위 토크 주입(더더링, 개루프라 발산 위험
  없음)해서 지름길을 데이터로 봉쇄. 15세션 재수집+재학습+SITL 재검증 결과
  **발산 완전히 해소**, default/strong 사실상 중립(-2.7%/-5.8%, 초기 대비 손해
  10배 이상 감소).
- **`TAU_FF_GAIN` 재스윕으로 첫 순이익**: gain 1.0→0.2로 낮추자 부호가 바뀜 —
  default +2.8~3.8%, strong +3.2% 실제 개선. 5조건(calm/light/default/strong/
  crosswind) 재검증도 3/5 개선으로 병진 A/B(4/5)와 같은 패턴. 스폰 yaw에서
  180도로 회전시켜도 개선 방향 유지(strong +5.0%로 오히려 더 좋음) — gain=0.2가
  특정 yaw 우연이 아님을 확인. 세미나 원 과제가 실제로 작동·도움이 되는 첫 사례
  (EXPERIMENTS.md 12-16/17절).

### 6. gust 정확도 "구조적 한계" 결론이 틀렸음을 확인 — yaw 그리드로 5배 개선
3절의 gust MAE 1.8m/s 벽은 yaw 그리드 수정 이전, 좁은 yaw 범위 데이터 기준이었음
— 실제로 yaw 그리드로 gust를 재수집해본 적이 없었음. 병진·회전 둘 다 같은 원인
(yaw 다양성 부족)이었던 전례로 재검토.
- yaw 그리드 gust 재수집(60에피소드, ~25분) + 더더링 고정바람과 합쳐 5-fold
  재학습 → **speed MAE 1.794±0.520 → 0.355±0.018 m/s로 5배 개선**, fold별 편차도
  훨씬 안정적.
- 회전 성능 유지(물리잔차 3.02) 확인 후 회전 피드포워드(gain=0.2) 재검증 —
  default +2.1%, strong +1.7%로 여전히 순이익, 배포함.
- **gust A/B(병진) 3차 재검증**: **4/4 조건 전부 개선, 세 버전 중 가장 큰 폭**
  (light_gust +9.4%, default +53.8%, strong +51.8%, crosswind +60.5%) — 계속
  골칫거리였던 light_gust까지 확실히 개선.
- **결론**: 병진 고정바람(3절)·회전(5절)·gust(이 절) 셋 다 진짜 원인은 "모델
  한계"가 아니라 "좁은 yaw 범위 데이터"였음(EXPERIMENTS.md 12-18/19절).

### 7. fixed-wind A/B 4차 재검증(5/5) + 적응형 게인 시도(실패)
gust까지 yaw 그리드로 학습한 현재 체크포인트로 fixed-wind 5조건 A/B를 재확인 —
**5/5 전부 개선**(+20.1%~+77.7%, 4절의 4/5보다 좋아짐, gust 데이터를 섞은 게
병진 추정에도 도움이 된 것으로 보임). 이어서 `ACCEL_GAIN`을 풍속 비례 적응형으로
바꾸는 시도는 스무딩 유무 상관없이 고정 상수(5/5)보다 나빠(3/5, 1/5로 후퇴) 실패 —
"게인을 노이즈 있는 추정치의 함수로 만드는 것" 자체가 회전 피드포워드의 각속도
재도입 시행착오와 같은 계열의 함정이었음. 원래 값(0.15/1.0)이 최선이라는 결론이
재확인됨(EXPERIMENTS.md 12-20절).

## 결과 하이라이트

| 실험 | 지표 | 결과 |
|---|---|---|
| PID-only 베이스라인 (강풍 8.5m/s) | 정상상태 위치오차 | <5cm |
| PINN 바람 추정 (고정바람만) | 풍속 MAE | 0.37~0.5 m/s |
| PINN 바람 추정 (gust 포함, yaw 그리드, 5-fold) | 풍속 MAE | **0.355 ± 0.018 m/s** (구결과 1.79±0.52 대비 5배 개선) |
| PINN 바람 추정 (yaw 그리드 0~358도, 2700조건) | 풍속 MAE (val) | 0.469 m/s |
| yaw 일반화 검증 (학습 그리드에 없는 각도) | wind_vx/vy MAE | 0.229 / 0.241 m/s |
| PINN 보정 ON vs OFF (5조건 스윕, 고정바람+gust 둘다 yaw그리드) | 피크 위치오차 개선 | **5/5 조건 개선** (+20.1%~+77.7%) |
| PINN 보정 ON vs OFF (4조건 스윕, gust, 고정바람+gust 둘다 yaw그리드) | 피크 위치오차 개선 | 4/4 조건 개선 (+9.4%~+60.5%) |
| PINN 회전 방해토크 추정 (yaw 그리드, 5-fold) | 회전 물리잔차 | 0.763 ± 0.238 rad/s² |
| PX4 토크 피드포워드 A/B (더더링 데이터, gain=0.2, 5조건) | 자세 피크 편차 개선율 | 5개 중 3개 개선(default/strong/crosswind +1.0~5.5%) |

> **✅ 2026-08-19~20 업데이트**: 위 PINN 보정 A/B 두 줄(5/5, 4/4)은 원래 **1회 측정**
> 기준이었음. 5회 반복해보니 고정바람 결과가 노이즈에 크게 묻혀 재현 안 됐는데
> (EXPERIMENTS.md 12-22절), 원인을 추적해보니 **`CALM_SETTLE_S`/`PHASE_GAP_S`
> (조건 전환 시 안정화 대기시간)가 3s/2s로 너무 짧았던 것**으로 확정됨 — 5s/4s로
> 늘리자 표준편차가 최대 20배 줄어들고(default/strong/crosswind는 3~4%p 수준),
> 5/5 방향도 유지됨(12-23절). 기본값을 5s/4s로 이미 수정해뒀음 — **위 표의 두 수치는
> 이제 신뢰 가능한 수준으로 재확인됨.** gust/회전은 아직 새 settle-time으로
> 재검증 전(12-23절 "다음에 볼 것").
